Data Model — 2 New Tables

Added to existing Supabase. Green fields are FSRS placeholders — populated in sub-project 2.

vocabulary_cards
~650 rows seeded from Goethe-Institut A1 list
column type notes
card_id uuid PK
user_id uuid FK → users
word text e.g. "kaufen"
article text der/die/das/—
translation_tr text Turkish translation
example_sentence text German A1 example
topic text Goethe topic (family, work…)
pos text noun/verb/adj/adv…
status enum new / seen / struggling / known
seen_count int default 0
last_seen_at timestamptz
next_review_at timestamptz simple interval for now
stability float FSRS — null until sub-project 2
difficulty float FSRS — null until sub-project 2
created_at timestamptz default now()
learning_sessions
One row per study session
column type notes
session_id uuid PK
user_id uuid FK → users
started_at timestamptz
ended_at timestamptz null if in progress
phase_reached enum warmup/lesson/conversation/done
lesson_topic text e.g. "Selamlaşma"
words_reviewed uuid[] card_ids shown in warmup
words_introduced uuid[] new words taught this session
corrections_count int mistakes corrected
session_summary text LLM-generated end-of-session note
Review scheduling (sub-project 1): simple time-based rule — new words after 1 day, seen after 3 days, struggling same day, known after 7 days. Replaced entirely by py-fsrs in sub-project 2 without schema changes.
