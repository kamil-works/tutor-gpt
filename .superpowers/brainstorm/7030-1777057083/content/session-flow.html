Session Flow — Daily Study Arc

Every session follows the same three-phase structure. The LLM guides transitions naturally in chat.

User opens app → clicks Yeni Ders Başlat
API creates learning_session row · fetches due vocabulary cards
↓
1
ISITMA (Warmup)
~5 minutes · vocabulary review
→ Tutor shows 5–8 due vocabulary cards one by one in chat
→ For each word: Turkish translation + article + example sentence
→ User rates themselves: biliyorum / zorlandım / bilmiyorum
→ API updates card status + next_review_at
System prompt injection: today_due_cards: [{word, article, translation_tr, example}]
↓
2
DERS (Lesson)
~10–15 minutes · structured teaching
→ Tutor picks today's topic based on progression (e.g. selamlaşma → sayılar → renkler)
→ Teaches new grammar/vocabulary in Turkish with German examples
→ Introduces 3–5 new words → adds them to vocabulary_cards
→ Short mini-quiz at end: 2–3 questions to confirm understanding
System prompt injection: last_session_topic, progression_stage, words_known_count
↓
3
KONUŞMA PRATİĞİ (Conversation)
~10 minutes · free practice
→ Tutor sets a simple scenario using today's vocabulary (e.g. "Kendini tanıt")
→ User writes freely in German — tutor responds naturally
→ Mistakes corrected inline: "✓ Güzel! Ama 'Ich bin' yerine 'Ich heiße' daha doğal olur."
→ User can ask questions freely — tutor stays in Turkish for explanations
↓
Ders Sonu Özeti
LLM generates Turkish summary · session_summary saved to DB · learning_session.ended_at set · words_reviewed + words_introduced arrays updated
